# machine-learning-classification

This project leverages core Python data science libraries, including NumPy, Pandas, SciPy, Matplotlib, Seaborn, and Scikit-Learn—to build robust machine learning algorithms capable of handling both binary and multi-class classification tasks.

Model Training and Exploration: Decision Trees, Naive Bayes, Random Forest, Support Vector Machines (SVM), and K-Nearest Neighbors (KNN) Classifier.

Evaluation: Confusion Matrix, Accuracy, Precision, Recall, F1-Score, and Receiver Operating Curve (ROC) Curve & Area Under the Curve (AUC).
